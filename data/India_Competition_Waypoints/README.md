# India Paragliding & Hang Gliding Competition Waypoints Repository

> Inventory trimmed for the public repository: only the formats VTasker reads (.cup, .gpx, .wpt, .csv) are included. These sets were published by the clubs and organisers who made them and are not covered by the VTasker licence; see NOTICE.

This repository contains authentic, publicly available competition waypoint packages and task turnpoint cylinders used for paragliding and hang gliding competitions across India.

## Supported Flight Instruments and Navigation Formats

Files are provided across standard soaring and FAI competition formats:
- **.CUP** (SeeYou / Naviter / Oudie / XCSoar / LK8000 / Flymaster / XCTrack)
- **.GPX** (Garmin / General GPS / Mobile Navigation / XCTrack)
- **.WPT** (CompeGPS / TwoNav / Flymaster / Fast-Score / FS / OziExplorer)
