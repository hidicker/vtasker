# France Paragliding & Hang Gliding Competition Waypoints Repository

> Inventory trimmed for the public repository: only the formats VTasker reads (.cup, .gpx, .wpt, .csv) are included. These sets were published by the clubs and organisers who made them and are not covered by the VTasker licence; see NOTICE.

This repository contains publicly available waypoint packages, competition turnpoint cylinders and mountain turnpoints used for paragliding and hang gliding competitions and cross-country (XC) flying across France.
